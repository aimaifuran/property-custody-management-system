# Offline office records

Open the three-dot menu beside the admin profile and choose Offline Records. Add the recipient name and office; no email, password or login account is created. Edit changes directory details while retaining the same record reference.

Request Item opens a new RIS with the offline office and recipient filled in. View Records also displays pending requests until issuance. In RIS, select the recipient under User account or offline recipient. For a new recipient, choose Enter an offline recipient manually, enter name and office, and click Save Offline Recipient. Complete the request and use the existing review and approval buttons. Approved supply requests deduct stock; assets create ICS/PAR using the existing unit-cost rule. The generated documents and accountability retain the offline reference.

Offline Records > View Records shows issued items and confirmed returns. Enter the received return quantity and choose Serviceable or Unserviceable, then click Returned. The system posts the stock/accountability movement and saves a PRS. Only serviceable returns increase available stock; unserviceable returns remain in return history for disposal. Fully returned items move out of Issued items into Returned items with a green Successfully returned badge. Partial returns retain the remaining item under Issued items. Partial and unserviceable returns can be recorded directly in View Records. The PRS form remains available for returns needing additional document details.

User Management uses the same returned-item display. Offline recipients stay separate from login accounts even when names match. Their records are available only to admins. Creating an offline directory record does not issue stock; RIS approval performs issuance.
